# Java 记事本 AI 编程大作业设计规格

日期：2026-05-28

## 1. 背景与目标

本规格用于 Java 大作业 1 的 AI 辅助编程任务。目标是在现有 `xmu-java-prog` 仓库中新建 `JAVA_BIG_HOMEWORK_1/`，开发一个接近 Windows 记事本体验的 Java Swing 桌面程序，并准备可提交的代码、实验报告材料和视频录制说明。

作业提交物包括：

- 记事本程序代码。
- Word 格式实验报告。
- 程序运行视频，视频中需要在记事本中输入 `22920242203267 李富悦`。

视频由用户自行录制；项目中提供录制步骤清单，确保覆盖必需内容。

## 2. 已确认决策

- GUI 技术：使用 Swing。
- 作业目录：使用 `JAVA_BIG_HOMEWORK_1/`。
- 报告格式：使用 Word `.docx`。
- 截图策略：尽量生成程序运行、编译运行、关键功能截图；AI 代码生成过程截图仍建议用户最终确认。
- 视频策略：不自动生成视频，由用户自行录屏，项目提供录制步骤。
- 录屏输入内容：`22920242203267 李富悦`。

## 3. 备选方案与选择理由

### 3.1 方案 A：Swing 多类结构，无 Maven

新建独立目录，使用 `javac` 编译，源码拆分为入口、主窗口、文件服务、查找替换、字体选择、状态栏等类。

优点：

- 与 Windows 记事本的传统桌面控件风格接近。
- 不需要额外 Maven 依赖，老师运行和检查更直接。
- 多类结构便于报告说明 AI 如何拆分任务和生成代码。

缺点：

- 字体选择等控件需要自行组合 Swing 对话框。

结论：采用此方案。

### 3.2 方案 B：Swing Maven 工程

用 Maven 管理编译运行，结构更规范。

优点：

- 构建流程统一，后续扩展测试更方便。

缺点：

- 对这个作业偏重，提交和运行依赖 Maven。

结论：不采用。

### 3.3 方案 C：单文件 `Notepad.java`

所有逻辑放到一个 Java 文件。

优点：

- 开发最快，文件数量少。

缺点：

- 查找替换、文件保存、字体、状态栏等逻辑会集中在一个大类中，维护性差，报告中也不容易体现工程化设计。

结论：不采用。

## 5. 功能设计

程序主界面采用 Windows 记事本式布局：顶部菜单栏，中间文本编辑区，底部状态栏。

### 5.1 文本编辑

使用 `JTextArea` 作为核心编辑控件，支持输入、删除、修改、复制、粘贴、剪切、全选等基础文本编辑能力。

### 5.2 文件菜单

`文件` 菜单包含：

- 新建。
- 打开。
- 保存。
- 另存为。
- 退出。

新建、打开、退出前，如果当前文档有未保存修改，弹出“保存 / 不保存 / 取消”确认框。保存和另存为使用 `JFileChooser`，默认处理 `.txt` 文本文件。

### 5.3 编辑菜单

`编辑` 菜单包含：

- 撤销。
- 剪切。
- 复制。
- 粘贴。
- 删除。
- 查找。
- 替换。
- 全选。
- 时间/日期。

撤销使用 Swing 的 `UndoManager`。时间/日期将当前时间插入光标位置。

### 5.4 查找与替换

`FindReplaceDialog` 提供查找和替换能力：

- 查找下一个。
- 替换当前匹配项。
- 全部替换。

空查找词不执行操作并提示用户。没有找到匹配内容时显示提示框。匹配时选中文本编辑区中的对应内容，方便用户确认位置。

### 5.5 自动换行

`格式` 菜单提供自动换行开关。开启时 `JTextArea` 根据窗口宽度换行；关闭时显示横向滚动条，更接近 Windows 记事本行为。

### 5.6 状态栏

状态栏显示：

- 当前光标位置：`第 x 行，第 y 列`。
- 当前缩放比例：例如 `100%`。

状态栏随光标移动、文本修改、缩放操作实时更新。`查看` 菜单提供显示或隐藏状态栏的开关。

### 5.7 字体设置

`格式 -> 字体` 打开 `FontChooserDialog`，允许选择：

- 字体族。
- 字形。
- 字号。

确认后将字体应用到整个文本编辑区。取消时不改变当前字体。

### 5.8 缩放

`查看` 菜单包含：

- 放大。
- 缩小。
- 恢复默认缩放。

缩放通过调整文本区字号实现，每次增减 2pt，限制在 8pt 到 72pt 范围内。状态栏同步显示相对缩放比例。

### 5.9 帮助

`帮助 -> 关于` 显示程序名称、作业说明、作者信息和技术栈。

## 6. 代码结构设计

### 6.1 `NotepadApp`

程序入口。负责设置 Swing 外观，并在事件派发线程中创建 `NotepadFrame`。

### 6.2 `NotepadFrame`

主窗口类。负责组装菜单栏、文本区、滚动面板、状态栏和各类事件处理。主窗口可以调用服务类和对话框，但不直接承担文件读写细节。

### 6.3 `DocumentModel`

记录当前文档状态：

- 当前文件路径。
- 文档标题。
- 是否已修改。

主窗口标题根据该模型更新，未命名文档显示为“无标题 - AI 记事本”。

### 6.4 `FileService`

负责文本文件读写：

- 使用 UTF-8 读取文本。
- 使用 UTF-8 保存文本。
- 统一封装 `IOException`，由调用方决定如何提示用户。

### 6.5 `FindReplaceDialog`

独立查找替换对话框。它接收主文本区引用或必要回调，专注于查找、定位、替换逻辑。

### 6.6 `FontChooserDialog`

独立字体选择对话框。通过 Swing 列表、下拉框或微调框选择字体族、字形、字号，并返回用户确认后的 `Font`。

### 6.7 `StatusBar`

状态栏组件。提供方法更新光标行列号、缩放比例和可见性。

## 7. 数据流与状态变化

### 7.1 文本修改

用户编辑 `JTextArea` 后，文档监听器将 `DocumentModel.modified` 标记为 `true`，主窗口标题显示未保存状态。

### 7.2 保存文件

保存流程：

1. 如果已有文件路径，直接调用 `FileService.save`。
2. 如果没有文件路径，打开 `JFileChooser` 执行另存为。
3. 保存成功后更新当前文件路径，清除修改标记，刷新窗口标题。

### 7.3 打开文件

打开流程：

1. 检查当前文档是否需要保存。
2. 用户确认后打开文件选择器。
3. 使用 `FileService.open` 读取文本。
4. 更新编辑区内容、当前文件路径、修改状态和窗口标题。

### 7.4 查找替换

查找替换对话框读取用户输入，在主文本区当前光标位置之后搜索。找到后选中匹配区间；替换操作修改文本区内容，触发文档修改状态。

## 8. 错误处理

- 文件打开失败：显示中文错误提示，保留当前文档内容。
- 文件保存失败：显示中文错误提示，保留修改状态。
- 未保存确认：取消操作时回到当前编辑状态，不丢失内容。
- 查找词为空：提示用户输入查找内容。
- 查找无结果：提示没有找到匹配内容。
- 字号缩放越界：保持在 8pt 到 72pt 范围内。


报告至少包含：

- 实验目的。
- 作业要求分析。
- AI 辅助开发提示词。
- AI 生成代码过程截图。
- 程序结构说明。
- 功能实现说明。
- 编译运行和功能截图。
- AI 使用总结，包括 AI 擅长解决的问题、提示词怎么写效果更好、使用 AI 过程中的困难和解决方法。

## 13. 非目标范围

本项目不实现以下功能：

- 多标签页编辑。
- 富文本格式。
- 语法高亮。
- 自动保存。
- 打印。
- Windows 注册表或系统级文件关联。

这些功能超出“尽量接近 Windows 记事本”的作业核心要求，会增加实现复杂度和报告负担。
