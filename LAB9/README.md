# LAB9 JavaFX 实验

## 运行方式

```bash
mvn javafx:run
```

## 内容

- `src/main/java/com/example/demo/HelloApplication.java`：JavaFX 程序入口。
- `src/main/java/com/example/demo/ManagementPane.java`：学生查询、课程管理、选课管理。
- `src/main/java/com/example/demo/PainterPane.java`：矩形、圆形、直线绘图与颜色对话框。
- `make_screenshots.py`：生成报告第六部分使用的运行效果截图。
- `build_report.py`：生成 `JAVA实验报告LAB9.docx`。
